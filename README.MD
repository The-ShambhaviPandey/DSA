# Data Structures and Algorithms with Java

Welcome to my **DSA with Java** repository — a personal journey of mastering algorithms, logic building, and problem-solving one line of code at a time.

This repo covers everything from **core Java fundamentals** to **data structures**, **algorithm analysis**, and **coding patterns** for interviews.

---

## Tools & Technologies

- **Language:** Java (JDK 21)
- **Editor:** VS Code 
- **Build Tool:** javac 
- **Version Control:** Git & GitHub

---

## How to Run Code

1. Clone the repository:

   ```
   git clone https://github.com/theshambhavipandey/DSA-with-Java.git
   cd DSA-with-Java
   ```

2. Navigate to a specific folder:

   ```
   cd 01_Basics
   ```

3. Compile and run:

   ```
   javac FileName.java
   java FileName
   ```
